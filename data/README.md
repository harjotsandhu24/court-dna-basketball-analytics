# data/

Intermediate pipeline output — `canonical_player_seasons.csv`,
`features_traits.csv`, `with_archetypes.csv`, `galaxy_coords.json`,
`team_stints.csv`, `source_manifest.json`. Generated by `analysis/step1`
through `step5`, then compacted into `public/data/` by `step6` for the
frontend.

This folder is gitignored and regenerated by running the pipeline (see the
root `README.md`). It isn't required to run the app itself, only to
reproduce or audit the analysis from source. Raw source CSVs live in
`raw/`, also gitignored — see `docs/data.md`.
