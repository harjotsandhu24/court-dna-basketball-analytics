# data/

Intermediate pipeline output (`canonical_player_seasons.csv`, `features_traits.csv`,
`with_archetypes.csv`, `galaxy_coords.json`, `team_stints.csv`, `source_manifest.json`)
is generated here by `analysis/step1` through `step5`, then compacted into
`public/data/` by `step6` for the frontend to consume.

This folder's contents are gitignored and regenerated by running the
pipeline — see the root `README.md` "Rebuild the analytics" section. They
are not required to run the web app itself, only to reproduce or audit the
analysis from source.
